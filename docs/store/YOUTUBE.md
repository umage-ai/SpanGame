# YouTube: the teaser and what to enter

| File | What |
|---|---|
| `youtube/span-teaser.mp4` | the teaser: 38 s, 1920 × 1080, 30 fps, H.264 + AAC, music generated locally (ACE-Step) |
| `youtube/span-teaser-thumbnail.jpg` | the custom thumbnail, 1280 × 720 (the bus going into the water) |

To make it again from the current game: `npm run teaser -- --music <file>` writes `dist/teaser/span-teaser.mp4` (the shots and captions are in `tools/teaser.js`; without `--music` the video is silent). Copy the new video here when it replaces this one.

## Upload fields

| Field | Value |
|---|---|
| Title | SPAN: Bridge Builder – Teaser \| Build it. Test it. Don't drop the bus. |
| Description | the text below |
| Thumbnail | `youtube/span-teaser-thumbnail.jpg` |
| Playlist | SPAN (or umage.ai Studio games) |
| Audience | No, it's not made for kids (a general audience game; *made for kids* turns off comments and end screens) |
| Altered or synthetic content | No: the footage is the real game, recorded frame by frame. YouTube's disclosure is for realistic people, places or events, which this isn't |
| Paid promotion | No |
| Category | Gaming |
| Game title | leave empty (SPAN isn't in YouTube's game list yet) |
| Video language / caption language | English |
| License | Standard YouTube License |
| Comments | On |
| End screen | from 0:33: a subscribe element and a link to the itch.io page or the channel's playlist (external links need YouTube Partner Program) |
| Visibility | Public, or Unlisted to embed on studio.umage.ai and itch.io first |
